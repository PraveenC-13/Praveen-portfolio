---

## 4. Production Build & Deployment to Vercel

```bash
# Build production bundle
npm run build
```

### Deploying to Vercel:
1. Push this repository to your GitHub account (`https://github.com/PraveenC-13/portfolio-mine`).
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your repository. Vercel will automatically detect Vite:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Click **Deploy**. Your custom domain or vercel.app link will be live instantly.
